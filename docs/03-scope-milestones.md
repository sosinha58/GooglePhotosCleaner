# Scope by Milestone

> Part of the PhotoTidy PRD set. Index: `README.md`. Rules for agents: `AGENTS.md`.

## 4. Scope by milestone

| Milestone | Name | In scope (summary) |
|---|---|---|
| **M0** | Spikes & scaffolding | S-01..S-03, repo, CI, test harness, fake Google Photos fixture page |
| **M1** | Scan & index | FR-001..FR-020: scan loaded view, metadata index, date and pixel filters |
| **M2** | Duplicate detection | FR-030..FR-050: exact and near duplicate groups, keeper selection |
| **M3** | Review & trash | FR-060..FR-090, SAF-*: review UI, select, move-to-trash flow, savings report |
| **M4** | Quality + Takeout | FR-100..FR-125: bad-photo detection, Takeout import, StorageAdapter abstraction |
| **M5** | Hardening & release | NFR-*, privacy policy, store listing assets, legal sign-off |

Out of scope for all milestones above: see docs/01-product-overview.md §1.4.
